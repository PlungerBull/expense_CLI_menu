2 · Proposed — reconcile list as a table (pick A or B)
A — no Id column. Matches every other list table (accounts/categories/hashtags show no ids; ids come from --json or get). Mirrors the TUI's approved columns.
A · recommended
$ expense reconcile list
Account    Name                  Period                      Begin       End  Source   Status
---------  --------------------  -----------------------  --------  --------  -------  ---------
BCP Soles  Statement April 2026  2026-04-01 → 2026-04-30  1,000.00  1,500.00  chained  draft
BCP Soles  Statement March 2026  2026-03-01 → 2026-03-31    850.00  1,000.00  manual   completed
Cash USD   Q1 cash count         2026-01-01 → 2026-03-31    120.00     80.00  manual   completed
Account resolves via the replica name map (raw UUID in --no-cache/stateless mode, same as inbox). Status: 1→draft, 2→completed (same map as the TUI). Source replaces the [manual]/[chained from …] marker lines.
B — Id column last. Every reconcile action (get/update/complete/revert/delete) takes an ID; with B the list alone feeds the next command — no --json detour. Costs ~38 columns of width.
B
$ expense reconcile list
Account    Name                  Period                      Begin       End  Source   Status     Id
---------  --------------------  -----------------------  --------  --------  -------  ---------  ------------------------------------
BCP Soles  Statement April 2026  2026-04-01 → 2026-04-30  1,000.00  1,500.00  chained  draft      8c1d4b2e-6a9f-4e3d-b1c7-2f5a8e9d0c34
BCP Soles  Statement March 2026  2026-03-01 → 2026-03-31    850.00  1,000.00  manual   completed  5e2a9c07-1b8d-4f6a-9e3c-7d4b0a1f8e52
Cash USD   Q1 cash count         2026-01-01 → 2026-03-31    120.00     80.00  manual   completed  d7f3e1b9-4c2a-48d5-a6e8-9b0c3f7d2a16
Same table as A plus Id. Note: accounts/categories/hashtags tables would stay id-less — B makes reconcile the one exception.

3 · Proposed — Deleted column for accounts + categories (pick C or D)
The nit: today --include-deleted fetches soft-deleted rows but nothing marks them — Cash USD below is deleted and indistinguishable
today

Name       Currency  Person  Color     Balance  Archived

Old BCP    PEN       no      #808080      0.00  yes

Semantics to confirm
· Detail lost vs today's dump: the table drops user_id, home-currency balances, sort_order, version, timestamps, and the upstream id behind "chained" — all still available via reconcile get <id> or --json (verbatim engine body, unchanged). Flag any field you want kept as a column.
· Status labels draft/completed reuse the TUI's map — it moves into the commands layer (shared, per §5 dedup) so there is exactly one copy.
· Sorting stays the engine's order, rendered verbatim — no client-side sort.
· Deleted cell is format_bool(deleted_at) → yes/no, identical to hashtags.
· Empty state "(no reconciliations)" and the pagination hint are unchanged.
