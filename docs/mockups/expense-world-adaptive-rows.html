STEP 4 — MECHANICS notes, nothing to pick
· Measured, not a formula: each screen measures the real space its panel gets (screens with legends, split reconciliation panes, and the 2-line CheckList differ), on mount and on every terminal resize.
· Resize keeps your place: the page re-snaps so the cursor row stays on screen; in fetched-page mode the refetch re-anchors the offset to the first visible row.
· Floor of 5 rows: below a ~16-line terminal the panel clips again (today's behavior) — the TUI was never usable there; nothing is spent on it.
· CheckList: same rule in items — items = fit ÷ 2 (two physical lines each).
· CLI untouched: human mode keeps limit=20 + the offset hint; stdout has no viewport. --json stays byte-verbatim. DEFAULT_PAGE_ROWS remains the shared floor-of-truth for the CLI and the TUI's fallback before first measure.
· The dead scrollbar is gone structurally: the panel always fits, so #content never overflows — no scrollbar to drag, nothing clipped, footer and subtitle always visible.
