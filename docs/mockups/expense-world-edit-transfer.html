Edit = the same bar, pre-filled. Reached by hitting enter on a row in Transactions / Inbox. ctrl+↑/↓ to a field, retype, ctrl+s saves only what changed.
Locked fields are faded (lighter tone, no icons) with a “read-only” tag; ctrl+↑/↓ skips them. Only happens for reconciled transactions / transfer legs — normal entries lock nothing.
Transfer = the same Log flow + one optional field (“Transfer to?”). Empty → normal entry continues to Category. Set → it’s a transfer.
To amount = opposite sign of Amount. Same currency: auto-mirrored (overwrite if needed). Different currency: you type the real received amount; the engine derives the rate.
No category or hashtags for transfers — category is engine-assigned (@Transfer, or @Debt if a person is involved); hashtags are skipped. Both omitted from the transfer summary.
Transfers are immutable after creation (delete + recreate to change) — hence the read-only fields when editing a transfer leg.
