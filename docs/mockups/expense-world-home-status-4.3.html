C's honest caveats
· The ping uses a 5 s read timeout — an engine cold-starting from sleep (>5 s to first byte) briefly reads "✕ engine unreachable" until the next refresh. Deliberate: better a rare false negative than a 10-second muted "checking…" on every launch.
· The dot is static — the original mockup's pulse animation has no terminal equivalent.
· Failures update this line only — never a toast; launching offline stays quiet.
· Refresh policy: recompute local state every time you return home (~1 ms); re-ping only if the last result is older than 60 s. No flicker, no ping storm.
