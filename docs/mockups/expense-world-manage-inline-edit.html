Is it possible? Yes — here's what it costs
The row cursor already exists; the cell cursor and in-cell typing don't. It's a self-contained addition to the list widget (cursor_list.py): track a selected column + an edit buffer, intercept keys while editing (printable → append, backspace → pop, ↵ → PUT, esc → revert), render the live cell as text▏. Not free, but small — and the editable surface is tiny (name, color, status).
What it buys
  1. One surface. No detail, no pushed form — delete both manage_detail.py and the Manage path through the bar-form.
  2. Fastest possible edit: land on a cell, type, ↵. Airtable/spreadsheet muscle memory.
  3. Archive stops being a mystery key — it's just “edit the Status cell”.
What it costs
  1. A second edit idiom: Inbox / transactions / reconciliations still edit via pushed bar-forms. Only the 3 Manage lists get in-cell edit.
  2. Color is the awkward cell — pick X (cycle) or Y (strip).
  3. Create stays a form. Inline edit only touches name/color; a new account needs currency + type at birth (picks, not text), so n keeps the New form. Inline = edit + archive, not create. (Category/Hashtag inline-create would be easy later — name only.)

Two picks to lock before code
  1. How editing starts — (a) explicit: ↵ or e opens the cell, then type. Or (b) type-to-edit: on a text cell, just start typing; ↵/esc commit/cancel. (a) is safer — a stray keystroke can't mutate; (b) is faster. Leaning (a).
  2. Color — X cycle in the cell (fewest parts) or Y strip under it (see every swatch, reuses the New-form palette list). Leaning Y.

My take
Inline edit is the right end-state for these three lists specifically — they're the flattest records in the app, and the edit-in-place model is exactly your Todoist/Airtable instinct. The only thing I'd flag: it's bespoke UI that three screens use, so if you'd rather not carry a second edit idiom, Alt A from the previous mockup (enter → the existing bar-form, a archives) reuses everything already built and ships far sooner. Inline is the nicer surface; Alt A is the cheaper one. Tell me which world we're in — and if inline, your picks on the two questions above.
