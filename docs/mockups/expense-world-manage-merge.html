Recommendation — Alt A
It's the pattern the app already ships: the Inbox list runs p promote / d delete on the highlighted cursor row (each with a naming confirm) and opens the edit form on enter — no detail hop (inbox.py). Accounts/Categories/Hashtags are the only Manage screens that force the extra screen, so Alt A makes them consistent and deletes manage_detail.py outright. Enter → edit-form still honours the enter-never-mutates contract (opening a form writes nothing; the write is ^s).

On your original worry — "a fires on any stray row"
That drove Option B in the first place. Three things answer it now: the cursor row is reverse-highlighted, the confirm modal names the exact record (“Archive ‘Interbank PEN’.”), and — the clincher — the rest of the app already works this way. The detail screen turned out to be the inconsistent one, not the safe one.

The one real constraint the merge must carry
The system category (@Opening): e is allowed (engine keys it by system_key), a must stay hidden (archive/delete 403). Today that lives in check_action on the detail. On the list it re-evaluates per cursor row (Textual refresh_bindings on cursor move): Alt A / C simply omit a from the footer while a system row is highlighted; Alt B shows Archive greyed with the reason — arguably the clearest of the three on this one point.

Same three keys across all three Manage lists
· Account: e name + color (currency immutable, shown read-only) · a archive.
· Category: e name + color · a archive (hidden for system).
· Hashtag: e name · a archive.

Pick one
  1. Alt A — enter edits, a archives the row. Fewest keys, matches Inbox, deletes the detail screen. (recommended)
  2. Alt B — enter opens a tiny action menu (Edit / Archive). Keeps a "opened this record" beat and reads the system-lock cleanly, at the cost of one extra keystroke to edit.
  3. Alt C — no enter action; e/a are labelled footer keys. Flattest, but a dead enter key may feel odd where every other list opens something.
All three move archive onto the list and delete the read detail — the difference is only what enter does.
