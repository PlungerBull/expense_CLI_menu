Create forms reuse the same bar-cycle as Log — Name › (currency / color picks) › ctrl+s. New account is bank-only (Name · Currency PEN/USD · Color); the engine forbids is_person on create. Person accounts need the People API (Phase 4, not yet implemented).
Reconciliations are per-account. Pick an account, see its batches; each has a period, begin/end balance, and a source (chained/manual). No “difference” — the engine doesn't compute one or gate completion on a balance. “n” starts a new one.
New reconciliation: begin balance is chained by default (auto-carried from the previous batch's end) or manual (you type it). You can't set a value while chained (engine 422). End balance is your statement's closing balance (optional).
Detail: shows the assigned transactions (read-only) + begin/end balances with home equivalents. Assign attaches the statement's transactions to the batch; complete locks amount/account/title/date on them (the read-only fields you saw in Edit); revert unlocks; delete (draft only) cascade-unassigns.
⚠ Open question — how to assign? The mock shows a multi-select picker of the account's unassigned transactions (space to check, enter to bulk-assign). Alternative: a “Reconciliation” field on the transaction Edit screen (one at a time). Pick below.
Config is mostly read — shows engine/token/cache; “e/t” open small forms to change engine url / token. (⚠ token is a secret — masked, never logged.)
Auth shows identity + main currency; “bootstrap” provisions a new user's settings (one-time), “set main currency” PUTs the profile (and triggers the engine's home-currency recompute).
