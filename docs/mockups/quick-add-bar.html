Quick-add bar — Todoist-style, super simplistic

One floating bar drawn in HTML/CSS (exactly like Todoist’s own, which is React-in-Electron). Empty it’s just a prompt; as you type, recognised tokens light up and resolved fields appear as pills.

Top line = your raw text, recognised tokens highlighted. Bottom = resolved pills the parser returned — each maps to one engine field (amount · category · date · account). Leftover “coffee” becomes the note.

Why this is achievable: Todoist’s desktop app is Electron (Chromium) rendering React — its bar is HTML/CSS/JS, and the font is just the system UI font (SF Pro). So this exact drawing loads unchanged into Hammerspoon’s hs.webview (fastest, no app to ship) or Tauri (a real menu-bar app on the system webview — no 100MB Electron runtime).

Keeping the pills honest: each keystroke calls expense add --dry-run --json "coffee -5 today #food amex", which returns the parsed fields without writing. The bar renders that JSON — parsing lives once in the CLI/engine, never re-implemented in the bar. Enter → the real write.
