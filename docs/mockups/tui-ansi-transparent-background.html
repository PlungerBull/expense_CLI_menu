Confirm modal. We keep the dim scrim (override ModalScreen:ansi, which otherwise drops it) so the modal still reads as "on top".
What actually changes One constructor flag — ExpenseApp(ansi_color=True) — makes Textual emit the terminal's default background (SGR 49) instead of our #0e0e11, so the fill and the window padding are literally the same pixels. In app.tcss the base fills (Screen, #menu) move to ansi_default, and a Screen:ansi { color: $foreground } rule keeps body text at #d6d6da rather than letting it follow the terminal's own text colour. What does NOT change The theme stays non-ANSI, so every design token keeps its authored hex: net/spent red, owed green, the grey selection bar, the $surface header rule + group separators, the footer. Scrollbars and footer keys are not restyled — Textual's ansi-blue/ansi-magenta overrides are scoped to the ctrl+p key panel only. The two backgrounds, exactly
